oagentkit

Open Agent Kit —— Agent / LLM 编排工具链模块矩阵

13 个独立发版的 Go 模块，依赖严格自底向上，每仓独立 SemVer + 独立 CI。 每个仓库根目录都有 AGENTS.md，是面向 AI Agent 的权威规范。

模块矩阵

guardxtier 0安全围栏——凭据脱敏/SSRF 防护/工具许可判定/Shell 沙箱解析/审计—

快速开始

go get github.com/oagentkit/llm@latest

安装一律用上表的模块路径。不要引门面仓 oagentkit/agentkit —— 它只是原单仓的 re-export 兼容层，v1.x 后退役。

基建

.github — 全 org 共享 CI 门禁（reusable workflow） · matrix-tools — 版本矩阵生成 / 审计 / import 改写 / 建仓 · versions.json — 机器可读版本矩阵 · llms.txt — LLM 模块索引

与 oekit 的关系

oagentkit 与 oekit（Open Easy Kit，Go 微服务工具链） 是两套独立矩阵，不是子品牌。oagentkit 依赖 oekit 的 pkg、 concurrency、logx。
